# Gift-бот «Отримати подарунок» — нативний канал Sitniks (варіант A)

> Точка входу в розмову для лід-магніту skin.one. Кнопка/хук «Отримати подарунок»
> веде клієнта в Telegram-бот, звернення нативно стає **чатом у Sitniks**, менеджер
> веде консультацію + продаж, клієнт отримує подарунок до першого замовлення.

**Дата:** 17.08.2026 · **Механізм:** бот підключений як канал Sitniks (Sitniks володіє webhook'ом).

---

## Чому саме так (підсумок дослідження Sitniks Open API)

Перевірено повну OpenAPI-специфікацію `https://crm.sitniks.com/open-api-json`:

- **Немає inbound-API.** `POST /chats/{id}/messages` (`SendChatMessageDto`: `text`,
  `attachments`, `replyToId`, `replyType`) завжди пише **від імені менеджера**. Поля
  напрямку / `isIncoming` / `sender` не існує. → Повідомлення клієнта не можна «влити» в
  Sitniks через API.
- **`POST /chats/initiate`** вимагає `phone` + `socialMediaIdentifier` уже підключеної
  підписки (`telegram_private` / `viber_private` / `whatsapp_private` або Instagram/FB).
  Бота там немає, і потрібен телефон. → Не підходить для анонімного тапу в боті.

**Висновок:** прозорий «бот-міст» неможливий. Єдиний спосіб, щоб розмова була **нативно
в Sitniks** — підключити бот **як канал Sitniks**. Наслідок: свого коду на боті немає, тож
кастомної inline-кнопки всередині Telegram теж немає — «Отримати подарунок» реалізуємо
через опис бота + автовітання Sitniks + deep-link у рекламі.

## Крок 1. Створити бота в @BotFather

1. У Telegram відкрити **@BotFather** → `/newbot`.
2. Ім'я (name, видиме): **`SKIN.ONE — косметолог онлайн`** (КАПСОМ — як логотип бренду).
3. Username: має закінчуватись на `bot`. Пріоритет: **`skin_one_bot`**, резерв
   `skinone_online_bot` / `skinone_expert_bot` (BotFather підкаже, чи вільне).
4. **Скопіювати токен** — знадобиться в Sitniks (крок 3).

> Напрям: **обличчя (skin.one.ua)**. Персона в чаті — «косметолог Анастасія».

### Оформлення бота (тут і живе «Отримати подарунок»)

- `/setdescription` — текст на порожньому екрані **над кнопкою «Запустити»** (бачать
  усі нові користувачі). Аудиторія «тепла» (постійні клієнти) → коротко, акцент на
  подарунку першим рядком:

  ```
  🎁 Подарунок до першого замовлення через Telegram
  Професійний підбір доглядової косметики онлайн 🌸
  ```

- `/setabouttext` — короткий опис у профілі, до 120 символів (бачать не всі — лише хто
  відкриє профіль бота або отримає його в пересиланні):

  ```
  Професійний підбір косметики онлайн 🌸 Консультація косметолога + подарунок до першого замовлення 🎁
  ```

- `/setcommands`:

  ```
  start - 🎁 Отримати подарунок
  ```

- `/setuserpic` — завантажити лого skin.one (опційно).

> ⚠️ Telegram НЕ дозволяє перейменувати вбудовану кнопку «Запустити»/«START» на
> «Отримати подарунок». Тому «Отримати подарунок» = (а) текст опису вище, (б) автовітання
> Sitniks після старту, (в) кнопка-посилання в рекламі/Instagram (крок 4).

## Крок 2. Автовітання через наш webhook (мінімальний код)

Бот керується Sitniks (webhook — у Sitniks), тож **окремого бота в `main.py` НЕ додаємо**
(інакше конфлікт двох споживачів апдейтів на одному токені). Але вбудованого автовідповідача
в цьому Sitniks **немає**, тому автовітання після `/start` шлемо через **наш існуючий
webhook-сервер** (`src/webhook_server.py`, той самий, що працює для спам-фільтра):

```
Sitniks (нове повідомлення) ──webhook──▶ Railway /webhook/sitniks
   └─ initialSource == "telegram_bot"  (перевірено на живому чаті)
      і чат ще не вітали (dedup _WELCOMED_CHATS)
      і менеджер ще не відповів (усі managerName порожні)
      ──▶ SitniksClient.send_message(chat_id, GIFT_WELCOME_TEXT)
            └─ Sitniks віддає це клієнту в Telegram
```

**Текст автовітання** (`GIFT_WELCOME_TEXT`, варіант A — подарунок-пробник, без порогу суми):

```
Вітаємо! 🎁 Напишіть у відповідь „Хочу подарунок" — і наш спеціаліст незабаром приєднається до розмови. 😊
```

**Захист від зациклення:** наша відповідь іде як повідомлення менеджера, але dedup-множина
+ перевірка «менеджер ще не відповів» гарантують одне вітання на чат.

**Залежність:** Sitniks-webhook «Повідомлення в чаті» має спрацьовувати і для Telegram-каналу
(не лише Instagram). Перевірити після деплою: `/start` з нового акаунта → має прийти вітання.
Якщо ні — доналаштувати підписку webhook у Sitniks на Telegram-канал.

## Крок 3. Підключити бот як канал у Sitniks

1. Sitniks CRM → **Налаштування → Інтеграції**.
2. Знайти **Telegram** (бот) → «Додати інтеграцію».
3. Вставити **токен** з кроку 1 → «Додати токен».
4. Sitniks сам ставить webhook. Після цього кожне звернення в бот = **чат у Sitniks**.

Джерело: https://sitniks.ua/integrations/telegram/

---

## Крок 4. Розподіл чатів на менеджерів (у Sitniks)

Автовітання роботизоване через наш webhook (див. Крок 2) — у самому Sitniks його
налаштовувати не потрібно (вбудованої функції там немає).

**Розподіл чатів** — увімкнути автопризначення Telegram-чатів на менеджерів за наявним
правилом розподілу (напрям «обличчя» → косметолог Анастасія / відповідальні).

## Крок 5. Кнопка «Отримати подарунок» у рекламі / Instagram

Тут і є літеральна кнопка, яку тисне клієнт:

- **Deep-link:** `https://t.me/<username_бота>?start=gift`
  (payload `gift` дасть у Sitniks перший рядок `/start gift` — маркер, що прийшли з акції).
- **Instagram:** посилання в bio (напр. через Taplink/лінк-агрегатор) з написом
  **«🎁 Отримати подарунок»**, або CTA-кнопка в рекламному оголошенні → веде на deep-link.
- **Сайт/лендінг:** кнопка «Отримати подарунок» з тим самим посиланням.

---

## Готово — підсумок воронки

1. Клієнт бачить кнопку **«🎁 Отримати подарунок»** у рекламі/Instagram/сайті.
2. Тап → відкривається бот, опис «🎁 Подарунок…», кнопка «Запустити».
3. `/start` → Sitniks створює чат → наш webhook шле автовітання «…напишіть „Хочу подарунок"».
4. Клієнт пише «Хочу подарунок» → менеджер підхоплює чат **у Sitniks**, консультує, продає,
   додає подарунок-пробник до замовлення.

## Що НЕ вийшло і чому (щоб не повертатись)

- Літеральна inline-кнопка «Отримати подарунок» *всередині* Telegram — несумісна з нативним
  каналом (Sitniks володіє webhook'ом). Якщо колись критично — варіант **C (два боти)**:
  наш бот з кнопкою → deep-link на нативний бот-канал Sitniks.
